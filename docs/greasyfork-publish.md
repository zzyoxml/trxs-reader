## 脚本描述（必填，支持 Markdown）

```markdown
为 [trxs.cc](https://trxs.cc)（同人小说网）提供沉浸式阅读体验。

> 这个网站阅读模式、夜间模式啥也没有。

## 功能

- **阅读模式**：全屏纯净排版，分章渲染，滚动到底自动追加下一章；目录侧栏可搜索章节号并跳转；自动记忆阅读进度
- **夜间模式**：站点级深色覆盖（不进入阅读模式也能用），另有日间 / 羊皮纸 / 护眼 / 夜间 / 纯黑 5 套配色；可按系统深色模式自动切换
- **去广告**：拦截 `document.write` 注入、MutationObserver 清理节点、CSS 隐藏广告位；保留 Cloudflare 验证 iframe
- **可调排版**：字号 14–34px、行距 1.4–2.6、页宽 520–1400px、5 种字体

## 快捷键

| 按键 | 作用 |
|---|---|
| `←` / `PageUp` | 上一章 |
| `→` / `PageDown` / `空格` | 下一章 |
| `T` | 目录侧栏 |
| `D` | 切换夜间 / 日间 |
| `Home` / `End` | 本章首 / 尾 |
| `Esc` | 关闭面板 / 退出阅读模式 |
| `R` | 阅读模式外进入阅读 |

## 说明

trxs.cc 全站为 **GB2312** 编码，通用正文提取方案在该站会拿到乱码，因此本脚本按站点真实 DOM 硬编码选择器，抓取与解析统一走 GBK 解码。

章节总数取自页面实际的 `{当前}/{总数}`，**不采信书名括号里标注的章节数**（站点该数字经常与实际不符）。

脚本仅改变页面显示方式，不抓取、不存储、不转载任何正文。请支持正版。

源码与测试：https://github.com/zzyoxml/trxs-reader （MIT）
```
